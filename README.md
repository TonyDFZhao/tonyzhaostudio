# Tony Dongfang Zhao — Painting portfolio

Static site in [`portfolio/`](portfolio/). Artwork JPEGs/PNGs live in [`Paintings/`](Paintings/) at the repo root.

## Local preview

```bash
python3 -m http.server 8080
```

Open http://localhost:8080/MANA/

## Edit content

See [`portfolio/README.md`](portfolio/README.md) — especially [`portfolio/js/site-config.js`](portfolio/js/site-config.js) for projects, image lists, and the homepage.

## Publish (GitHub Pages)

Deploy the **repository root** (where `index.html` lives), not only the `portfolio/` folder. Steps are in [`portfolio/README.md`](portfolio/README.md#publish-on-github-pages).
